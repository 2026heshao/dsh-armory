设计说明 · ① 入口按钮为次级 .dsh-mcp-btn + 计数徽标，放在 .dsh-mcp-skill-toolbar 右端（搜索与视图切换之后），不与页面级主操作争权重；徽标在 hover 时反白提示可点。 ② 套件行与单 skill 行共用 .dsh-mcp-quick-item 度量（28px 行高、name 最大宽 + 省略、desc 11px 省略），差异仅三处：层叠图标取 accent 色、计数徽标显示成员数、分组头「套件」弱化为 10.5px 小标题；点击套件 = 依次插入成员 /name（宿主 skill lexicon 原生语义，零宿主改动），插入后菜单关闭、草稿可见反馈。 ③ 弹窗左栏是新建的选择器组件（紧凑卡片 + 拖拽源 + 复用同一条 SKILL_CATS 分类轨道与 listSkills 数据源），看板列表本体不进弹窗、不被复用第二遍；编辑走「工作副本 → 保存提交 / 取消放弃」语义，底栏常驻未保存标记；成员区空态给出拖拽示意，drop 时整区高亮 + 2px 插入指示线。 令牌映射（本稿近似 → 宿主）：--mcp-accent #4d6bfe、--mcp-line #e2e8f1、bg-layer-2 #f6f8fc、圆角 sm 8 / lg 12 / panel 16、阴影 --dsw-elevation-prominent。分类色与 SKILL_CATS 一致（dev #4d6bfe / design #60a5fa / office #22c55e / auto #f59e0b / ops #6b7f9e）。
