技能收藏与菜单搜索

把「常用技能」从一条经常滚走的列表，变成输入框旁随时可点的一层。二级菜单保持「最近优先」的排序，但去掉「最近」徽章；搜索只影响展示，收藏只在三级展开，不参与二级排序。

深色与浅色同构图，按默认方向向右展开：一级在左，二级接在它右侧，三级再接在二级右侧。只有贴到视口右缘、右侧剩余不足 204px 时才整体翻到左侧（见 C ②）。

B / STATES四个局部状态

搜索只改展示，不改排序；套件组与收藏行在有 query 时隐藏。收藏为空和读取失败都不阻塞技能、MCP、专家和套件。

C / PLACEMENT三级菜单的方向与夹取

D / METRICS尺寸账与令牌近似

280px 按 border-box 计（宽高就是面板外框）：搜索 26 + 间距 2 + 收藏 28 + 间距 2 + 列表 168 + 管理按钮区 42 = 268；再加 padding 10 + 边框 2 = 280。两个管理按钮各 20px 是这里唯一的取舍。
